# Adding a new lab

For each new exercise, create a Markdown file under `labs/` and include:

1. Objective
2. Tool and command used
3. Observations copied accurately from the run
4. What you learned
5. A screenshot saved under `screenshots/`
6. A note about authorization and any redacted data

Do not claim a result that is not visible in your own output. Redact cookies, API keys, tokens, personal contact details, and other sensitive values before publishing.
